# kompyutarni-arhitekturi

# Каталог на компютърни конфигурации

**Проект по Компютърни архитектури**

## Цел на проекта

Целта на проекта е да бъдат представени пет различни компютърни конфигурации, предназначени за различни потребителски нужди. Всяка конфигурация включва избор на хардуерни компоненти, обосновка на избора и сравнение на цените.

## Съдържание

1. Бюджетен офис компютър
2. Работна станция
3. Геймърски компютър
4. Компютър за видеообработка и 3D
5. Домашен сървър

## Използвани платформи

- PCPartPicker – избор на компоненти и проверка на съвместимостта.
- Ardes – проверка на цени.
- Jar Computers – проверка на цени.
- Technopolis – проверка на цени.
- eMAG – проверка на цени.
- Ozone – проверка на цени.

## Основни изисквания

За всяка конфигурация са разгледани процесор, дънна платка, оперативна памет, дисково пространство, видеокарта, захранване, кутия и периферия.

Компонентите са подбрани според предназначението и бюджета на съответния компютър.

## Заключение

Разгледаните конфигурации показват как различните хардуерни компоненти могат да бъдат комбинирани според нуждите на потребителя. При избора са взети предвид производителността, съвместимостта, надеждността и цената.
