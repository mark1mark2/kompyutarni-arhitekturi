
# Конфигурация 3 – Геймърски компютър

**Бюджет: до 3000 евро**

## Предназначение

Компютърът е предназначен за съвременни игри с високи графични настройки, висока резолюция и плавна картина.

| SSD | 2TB NVMe PCIe 4.0 |

| Охлаждане | 240mm водно охлаждане |

| Монитор | 27-инчов 1440p |

## Обосновка

Избрах AMD Ryzen 7 7800X3D, защото е процесор, създаден с много добра производителност при игри. Неговата голяма кеш памет помага за постигането на висока честота на кадрите.

Видеокартата NVIDIA RTX 5070 Ti с 16GB VRAM е подходяща за игри при високи графични настройки и 1440p резолюция.

32GB DDR5 RAM осигуряват достатъчно памет за съвременните игри. SSD дискът от 2TB позволява съхранението на много игри и бързото им зареждане.

## Предимства

- Висока производителност при игри.
- Поддръжка на висока резолюция.
- Бърза оперативна памет.
- Добра възможност за бъдещи подобрения.
