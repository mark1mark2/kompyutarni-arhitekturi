
# Конфигурация 5 – Домашен сървър

**Бюджет: до 1500 евро**

## Предназначение

Домашният сървър е предназначен за съхранение на файлове, архивиране на информация, споделяне на данни и работа на различни услуги в домашна мрежа.

## Избрани компоненти

| Компонент | Модел |
|---|---|
| Процесор | AMD Ryzen 5 7600 |
| Дънна платка | B650 ATX |
| RAM | 64GB DDR5 |
| SSD | 1TB NVMe |
| HDD | 2x 8TB NAS HDD |
| Видеокарта | Вградена графика |
| Захранване | 650W 80+ Bronze |
| Кутия | ATX корпус с места за 4 HDD |
| Периферия | Монитор, клавиатура и мишка |

## Обосновка

Избрах AMD Ryzen 5 7600, защото предлага достатъчна производителност за домашен сървър и работа с различни услуги.

64GB RAM позволяват едновременно изпълнение на няколко задачи. NVMe SSD дискът се използва за операционната система и програмите.

Двата HDD диска с капацитет по 8TB осигуряват голямо пространство за съхранение на файлове. Те могат да бъдат конфигурирани в огледален масив, така че информацията да се запазва и на двата диска.

Огледалният масив обаче не заменя отделното резервно копие.

## Предимства

- Голям капацитет за съхранение.
- Подходящ за продължителна работа.
- Възможност за архивиране.
- Възможност за добавяне на още дискове.
